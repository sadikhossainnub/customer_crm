১. পরিচিতি ও উদ্দেশ্য (Overview)

MicroSIP ERPNext Bridge হলো একটি উইন্ডোজ নির্ভর সফটওয়্যার ইন্টারফেস, যা আপনার ডেস্কটপ কম্পিউটারে চলা MicroSIP Softphone এর সাথে ERPNext Customer CRM এর সরাসরি যোগাযোগ স্থাপন করে।

এর মাধ্যমে ইউজার ERPNext থেকে এক ক্লিকে কল করতে পারেন এবং কল শেষ হওয়া মাত্র কলের Duration (সময়কাল) ও Status (Completed/Missed) সম্পূর্ণ স্বয়ংক্রিয়ভাবে ERPNext-এ সংরক্ষণ হয়ে যায়।

২. সিস্টেম আর্কিটেকচার (Architecture Diagram)

[ ERPNext Browser UI ]
│
├── 1. Click "📞 Call via MicroSIP"
│ └── Sets Call Status = "Ringing" & Direction = "Outbound" via API
│
▼
[ MicroSIP Desktop Softphone ]
│
├── 2. Opens & Dials Customer Phone Number
└── 3. Call ends -> Saves record in %APPDATA%\MicroSIP\history.xml
│
▼
[ MicroSIP Bridge (Silent Windows Background Service) ]
│
├── 4. Detects new entry in history.xml
└── 5. POSTs Call Duration & ID to ERPNext API (update_call_from_microsip)
│
▼
[ ERPNext Server ] ➔ Updates Customer Call Record ➔ Triggers Realtime UI Auto-Reload!

৩. কল ডায়ালিং ও সিঙ্ক প্রসেস (Step-by-Step Workflow)

ধাপ ১: Click-to-Call সূচনা
ERPNext-এ Customer Call ফর্মে কোনো ফোন নম্বরের পাশে "📞 Call via MicroSIP" বাটনে চাপ দিলে সিস্টেম আগে রেকর্ডটি সেভ করে এবং ERPNext-এ কলটির স্ট্যাটাস Ringing ও ডিরেকশন Outbound সেট করে।
ধাপ ২: MicroSIP অটোমেটিক ডায়ালিং
ব্রাউজার থেকে microsip:PHONE_NUMBER হ্যান্ডলার ট্রিগার হয়ে আপনার পিসির MicroSIP সফটফোন অন হয়ে কল ডায়াল করা শুরু করে।
ধাপ ৩: উইন্ডোজ ব্যাকগ্রাউন্ড পর্যবেক্ষণ
MicroSIP সফটফোন কল শেষ হওয়া মাত্র %APPDATA%\MicroSIP\history.xml ফাইলে কলের ডিউরেশন সেভ করে। ব্যাকগ্রাউন্ডে চলা microsip_bridge.pyw সার্ভিসটি রিয়েল-টাইমে এই পরিবর্তন সনাক্ত করে।
ধাপ ৪: ERPNext এপিআই সিঙ্ক
ব্রিজ সার্ভিসটি সিকিউর API Key এবং Secret ব্যবহার করে ERPNext-এর update_call_from_microsip মেথডে ডেটা পাঠায়। সার্ভার উক্ত নম্বরের বিপরীতে থাকা Ringing কল রেকর্ডটি খুঁজে তার Duration এবং Status আপডেট করে দেয়।
ধাপ ৫: ব্রাউজার রিয়েল-টাইম নোটিফিকেশন
কল আপডেট সম্পন্ন হওয়া মাত্র ইউজার যে ব্রাউজারে কাজ করছিলেন সেখানে একটি গ্রীন নোটিফিকেশন টোস্ট ভেসে ওঠে এবং পেজটি অটো-রিফ্রেশ হয়ে সময়কাল দেখায়।

৪. ফাইল ও কম্পোনেন্ট বিবরণ (System Components)

ফাইল/কম্পোনেন্ট ধরন কাজ ও বিবরণ
microsip_bridge.pyw Python Application GUI কনফিগারেশন উইন্ডো এবং সাইলেন্ট ব্যাকগ্রাউন্ড থ্রেড রান করে।
install.bat Windows Installer প্রয়োজনীয় লাইব্রেরি ইনস্টল করে এবং উইন্ডোজ স্টার্টআপে সাইলেন্ট সার্ভিস রেজিস্টার করে।
call_api.py ERPNext Backend API mark_microsip_dial_start ও update_call_from_microsip এপিআই প্রদান করে।
customer_call.js ERPNext Frontend JS Click-to-call লজিক পরিচালনা করে এবং রিয়েল-টাইম সকেট ইভেন্ট গ্রহণ করে।
telephony_settings_list.js List View Script Telephony Settings লিস্ট পেজে Direct Download বোতাম প্রদর্শন করে।

৫. ইনস্টলেশন ও ব্যবহার পদ্ধতি (User Guide)

  1. ERPNext-এর Telephony Settings List View (/desk/telephony-settings) থেকে ⬇️ Download MicroSIP Bridge App বাটনে ক্লিক করে Zip ফাইলটি ডাউনলোড করুন।
  2. Zip ফাইলটি আনজিপ করে install.bat ফাইলেই ডাবল-ক্লিক করুন।
  3. স্ক্রিনে সেটিংস উইন্ডো আসলে আপনার ERPNext URL (https://erp.dressup.com.bd), API Key এবং Secret দিন।
  4. Auto Detect MicroSIP Path চাপুন এবং 🔌 Test Connection দিয়ে ভেরিফাই করুন।
  5. 💾 Save & Run in Background চাপুন। এটি উইন্ডোজের সাথে অটোমেটিক চালু থাকবে।
